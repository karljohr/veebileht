# Veebileht: Saagisalong

## Description
Veebileht hasartmängu elementidega, kus müüakse loosikaste, mille hinnad on suvalised aga kindlas vahemikus. Iga päev on poes ka uus kindel “Päevatoode”, mida on ainult 1 eksemplar ja mille hind langeb päeva möödumise jooksul.

## Autorid
Tiim Pingviinid:
 - Karl-Johannes Ränkel
 - Christofer Toom
 - Joonas Reier
